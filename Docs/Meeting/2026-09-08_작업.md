- 편집은 **전체 화면**. 위 미리보기, 아래 슬라이더. 게임 타이틀을 하단 패널로 가리던 오버레이는 없앴다.
- 연다: 타이틀 왼쪽 아래 금색 `UI`, 설정 `UI 편집`, 크레딧 제목 길게 누르기. 로컬 APK만. 스토어·공개 웹에는 없음.
- 언어 칩 한/EN/日/简/繁. 화면 칩 타이틀·인트로·마을·BGM·설정·크레딧·종료·포기·클리어·체험판.
- 스키마 3. 값은 `언어 × 화면` 칸. 공통 타원 칩 없음.
- **저장**은 스냅샷 + JSON 클립보드. **이 화면**은 마지막 저장으로 지금 칩만. **초기화 → 이 화면만**은 지금 칩만 기본값. **모든 화면**은 두 번 확인.

## 맞춘 버그

| 증상 | 원인·고친 것 |
| --- | --- |
| 글자만 바뀌고 폭·패딩·제목이 그대로 | 미리보기가 폰 전체 `MediaQuery`를 축소함. `using()`이 `LayoutBuilder` 전에 대상을 되돌림. 미리보기는 360×640 칸만 쓴다. |
| 글자를 키우면 타원 전체가 커짐 | 폭이 글자에 달라붙음. 폭 슬라이더가 타원 가로. |

| 저장 후 다른 화면에서 초기화하면 전부 날아감 | AppBar 초기화가 `reset()`. 모달 값이 언어 공통 `overlays`. 지금 칩만 `resetCurrent()`. |
| 인트로 영어 글자가 타원 끝만 따라감 | 별 안쪽 폭에 맞춰 글자를 줄임. 글자 슬라이더 그대로. 타원 끝은 별 여백만. 긴 영어는 두 줄. |
| 슬라이더는 다 15인데 버튼마다 크기가 다름 | 두루마리 19, 이어하기·마을 18, 마을 미션 라벨 14. 버튼 글자는 `PlayUi.button`만. 기본 15. |
