## 집에서 할 일 (입점 순서)

1. ~~**벌레 스킵 가리기**~~ — **완료.** `GameBalance.showTrialSkipButton` (`!STORE_BUILD && !WEB_DEMO`). `game_screen` AppBar `Icons.bug_report`는 로컬 디버그용으로만 남김.
2. **출시 서명** — 업로드용 jks 생성 + `android/key.properties`(git 제외, 예시는 `key.properties.example`). Gradle은 `key.properties` 있으면 release 서명, 없으면 로컬용 debug. Play App Signing 권장.
3. **스토어 AAB** — `flutter build appbundle --release --dart-define=STORE_BUILD=true`
4. **Play Console** — 앱 생성, 패키지 `com.tychespark.starlightsudoku`, 제목·설명에 **체험판**·Easy 10스테이지.  
   방침: https://spark.tycheworks.com/starlight-sudoku/privacy/  
   Data safety / IARC / 광고=없음 → 디자인검토 문서 초안 그대로.  
   아이콘·피처: `store/play_icon_512.png`, `store/feature_graphic_1024x500.png`
5. **스크린샷 4~8장** — 설치된 **STORE_BUILD APK/AAB**로. 퍼즐 포함. 벌레·UI 튜너·언어 디버그 없음. 웹 주소창 금지.
6. **내부 테스트** 트랙에 AAB 올린 뒤 실기기 → 문제 없으면 심사 제출.
