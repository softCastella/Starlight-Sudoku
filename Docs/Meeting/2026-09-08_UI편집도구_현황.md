# 2026-09-08 UI 편집 도구 — 현황과 규칙

제작자가 코드 고치지 않고 양피지·타원·두루마리 글자·크기를 맞추는 도구다. 이 문서가 **지금 구현된 동작**이다. 그날 한 일·APK: `2026-09-08_작업.md`. 같은 날 오전 계획서(`2026-09-08_UI모달_편집도구_후속작업.md` 1~11절)의 하단 32% 패널·공통 타원 칩은 폐기됐다.

회귀 목록: `Docs/Harness/검증.md` Play UI·설정. 입점: `Docs/Deployment/2026-09-04_Play_디자인검토.md`.

## 1. 어디에 있나

- **연다:** 타이틀 왼쪽 아래 금색 `UI`, 설정 안 `UI 편집`, 크레딧 제목 길게 누르기.
- **화면:** 위 미리보기, 아래 슬라이더. 게임 타이틀을 패널로 가리지 않는다.
- **로컬 APK**(`STORE_BUILD` 아님)에만 있다. 릴리스로 맞춰도 `kDebugMode`에 묶지 않는다.
- **스토어 AAB**(`STORE_BUILD`)·공개 웹(`WEB_DEMO`이고 `UI_TUNER` 없음)에는 없다. 스크린샷에 슬라이더·언어 칩이 보이면 실패.
- 브랜치: **`main`만.** `pages`에 올리지 않는다.
- 실기기 설치는 갤럭시 `SM-S931N` (`R3CY50FP0QD`)만. Quest에 넣지 않는다.

## 2. 어떻게 맞추나

1. 언어 칩: 한 / EN / 日 / 简 / 繁.
2. 화면 칩: 타이틀 버튼, 인트로 버튼, 마을 버튼, BGM 버튼, 설정, 크레딧, 게임 종료, 퍼즐 포기, 완료 보상, 체험판 종료.
3. 아래 슬라이더로 지금 칩만 고친다. 다른 화면·언어는 건드리지 않는다.
4. 슬라이더는 즉시 미리보기에 반영되고, 기기에 자동 저장된다.
5. **저장:** 지금 전체의 스냅샷 + JSON을 클립보드에 복사. 확정값을 코드에 넣을 때 이 JSON을 쓴다.
6. **이 화면:** 마지막 **저장** 스냅샷으로 **지금 칩·지금 언어만** 되돌린다. 저장한 적 없으면 기본값.
7. **초기화 → 이 화면만:** 지금 칩·언어만 코드 기본값. 이미 맞춘 다른 화면은 그대로.
8. **초기화 → 모든 화면:** 두 번 확인한 뒤에만 전부 기본값. 한 번 탭으로 전체가 날아가면 실패.

칩을 바꾸면 슬라이더가 그 화면 값으로 바뀌는 것이 정상이다. 타이틀을 맞춘 뒤 인트로로 가면 인트로는 아직 기본 15다. 타이틀로 돌아오면 맞춘 값이 있어야 한다.

## 3. 값 저장 구조

스키마 3. 기기 키 `play_ui_tune_v2`.

- 코드 기본값: `PlayUi` 상수 (버튼 글자 **15**, 제목 18, 본문 13, 라벨 14, 보조 11).
- 덮어쓰기: **언어 × 화면** 칸. `locales[en][openingButton][button] = 22`처럼 둔다.
- 예전 모달 전용 `targets` 맵이 남아 있으면 읽을 때 각 언어 칸으로 올린 뒤 비운다. 한 화면만 되돌려도 다른 언어가 같이 지워지지 않게 하기 위함이다.
- 공통 칩은 편집 화면에 없다. 열면 타이틀 버튼부터 고른다.

읽기 순서: 지금 언어·화면 칸 → 없으면 기본값.

## 4. 슬라이더가 하는 일

화면에 없는 슬라이더는 그 그림에 안 먹는 값이다. 빼 둔 것(최소 폭 등)을 다시 넣지 않는다.

### 타이틀 버튼 (두루마리)

| 슬라이더 | 동작 |
| --- | --- |
| 버튼 글자 | `PlayUi.button`. 기본 15. 19·18을 더하지 않는다. |
| 버튼 폭 | 두루마리 가로. 짧은 글자도 이 폭. |
| 두루마리 글자 패딩 | 스크롤 안 좌우 여백. |
| 버튼 글자 가로·세로 | 글자만 이동. |

글자는 스크롤 **세로 가운데**. 위로 올라가 잘리면 실패.

### 인트로 / 마을 / BGM / 모달 안 타원

| 슬라이더 | 동작 |
| --- | --- |
| 버튼 글자 | 그대로 적용. 영어를 별 안쪽 폭에 맞춰 줄이지 않는다. |
| 버튼 폭 | 타원 가로. |
| 버튼 높이 배율 | 타원 세로만. 두루마리에는 없음. |
| 타원 끝(별) 비율 | 별·뾰족한 부분 안쪽 여백. **글자 크기를 바꾸지 않는다.** |
| 버튼 글자 가로·세로 | 글자만 이동. |

긴 영어(`Light the first window` 등)는 **두 줄**까지. 넘치면 자른다. 한 줄로 11에 고정되면 글자 슬라이더가 안 먹던 버그였다.

### 양피지 모달 (설정·크레딧·종료·포기·클리어·체험판)

제목·본문(설정은 라벨), 안·바깥 여백, 최소·최대 폭, 줄 간격, 가로·세로 위치. 설정 라벨은 스위치 줄 글자다.

미리보기에서 모달은 360×640 칸의 `MediaQuery`를 쓴다. 기기 전체 크기를 축소하면 패딩이 안 보인다.

## 5. 버튼 글자 15

편집기 기본이 15인데 화면마다 달라 보이면 실패다. 원인과 금지:

- 두루마리에 19를 기본으로 두고 슬라이더 차이만 더하지 않는다.
- 이어하기·마을 보기에 18을 따로 박지 않는다.
- 마을 미션 타원에 라벨 14를 넣지 않는다.
- 영어가 길다고 타원 끝 비율로 글자를 줄이지 않는다.
- `FittedBox.scaleDown`으로 긴 영어만 작아 보이게 하지 않는다. (두루마리 글자가 맨 위로 붙는 실수는 가운데 정렬로 고쳤다. 글자 크기를 맞추려고 다시 빼지 말 것.)

타이틀·인트로·마을·BGM·모달 닫기 버튼은 그 칩의 **버튼 글자** 하나만 본다.

## 7. 아직 이 도구 밖

- 마을 `AlertDialog`, 스테이지 로딩 `Card`
- 퍼즐 보드 숫자, 타이틀 PNG, 하늘·창문
- 색·오버레이 투명도 슬라이더 (필드만 있고 패널에 없음)
- JSON을 저장소 기본값 파일로 자동 반영 (저장은 클립보드 복사)

## 8. 확인 목록

- 한에서 타이틀 글자 15, EN 인트로도 15. 인트로 EN 글자를 22로 올리면 커진다. 타원 끝만 움직여서 글자가 커지면 실패.
- 타이틀을 맞추고 저장 → 인트로에서 이 화면만 초기화 → 타이틀은 그대로.
- 초기화 한 번에 모든 언어·화면이 기본값으로 돌아가면 실패.
- 두루마리 글자가 스크롤 위로 잘리면 실패.
- 공개 웹·스토어 빌드에 `UI` 탭이 있으면 실패.
- 난이도·스테이지·마을 하늘은 스테이지 클리어 비율만. 이 도구와 섞지 않는다.
