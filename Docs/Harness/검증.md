# 작업 끝낼 때마다 검증

기능을 넣거나 고친 뒤, 배포 전에 이 목록을 화면별로 본다. “이번에 안 건드렸다”고 건너뛰지 않는다. 같은 배경을 쓰는 난이도·스테이지·마을은 항상 같이 본다.

최신 작업 기록: `Docs/Meeting/2026-09-04_작업.md`. 지금은 실기기 APK 테스트만. Play 콘솔은 그다음.

## 하늘·창문

- 밤 / 창문 불 / 아침은 **스테이지 클리어 비율**만 본다. `windowPoint` 0.42 미만은 밤, 1 미만은 창문, 1은 아침.
- 난이도 선택과 스테이지 선택의 마을 그림은 같아야 한다.
- 별빛 마을 그림도 같은 스테이지 비율이다. 빵집 5/5 같은 **건물 라벨**은 StarLight 복원량이고, 그림의 창문을 먼저 켜지 않는다.
- 체험판 Easy 10/10이면 난이도·스테이지·마을이 모두 아침.

## 타이틀·PWA 상단

- 타이틀에 반짝이는 별 레이어가 있다. 그림 **위**.
- 폴드처럼 가로가 넓으면 타이틀은 1080:2340 칸. 양옆은 별 남색. 그림만 `fitWidth`로 키우지 않는다.
- APK 상태바는 남색 `#0E2040`, 아이콘은 흰색.
- 웹 `theme-color`와 PWA `manifest.theme_color`는 `#0E2040`. 투명이면 Chrome이 노랗게 칠한다.
- **브라우저 주소창**의 빈 별은 북마크다. 우리 별은 주소창을 없앤 **홈 화면 추가(PWA)** 또는 APK에서만 보인다. 일반 탭·시크릿 탭의 흰 주소창은 정상이다.

## 별빛 마을 글자

- 「별빛 마을」, 복원 수, 스타라이트는 그림·빛 연출 **위**에 둔다.
- 아침이 되기 전에는 크림색 + 어두운 그림자. 중간 새벽색으로 흐리지 않는다.

## 스테이지 카드

- 클리어한 칸 오른쪽 위에 금색 별.
- 누르지 않은 1번을 선택처럼 표시하지 않는다.
- 쉬움: 고른 칸은 노랑+진한 노랑 테두리, 같은 행·열은 연한 노랑, 같은 숫자는 노랑. 보통·어려움은 칸만.

## 체험판 모달

- 10판 후 **스테이지 선택**에서 한 번. 타이틀·난이도·마을에서는 안 띄운다.
- 10판 후 모달. 리뷰 안내 문구. 보라 「이동하기」만 스토어로. 아이보리 「닫기」는 창만 닫음. 바로 스토어로 보내지 않음. 스토어에서 뒤로가면 이 창.
- `requestReview()`는 쓰지 않는다.

## 스토어 전에 끌 것

- 퍼즐 스킵(벌레) 버튼. **로컬 APK에는 아직 있다.** 스토어 AAB에는 넣지 말고 설정만 둔다
- 디버그 서명

## 손대지 말 것

- `sample-v1`
- 가비아 DNS 화면 (도메인은 가비아 구입, DNS는 이미 Vultr 위임)
